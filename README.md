# tiny-stack-vm

A tiny stack virtual machine for [make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) — the full ISA: 32-bit wrapping integers, 256-value stack, branches, calls, 256 words of memory, input/output, all ten traps with their own exit codes, and the step and output limits. Run with `node main.ts`; it answers all 40 instances of a set in one run.
